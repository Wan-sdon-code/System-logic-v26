# 📝 Python Script Notes

- `print()` → Shows words on the screen.
- `input()` → Lets the user type an answer.
- `anchor` → Saves the user's answer.
- `{anchor}` → Shows the saved answer.
- `\n` → Makes a new line.
- `"-" * 35` → Makes a line of dashes.

## 💡 What the Script Does

The program asks what you fall back on when life gets difficult.

It saves your answer.

Then it gives you four questions to think about:

**Purpose → Meaning → Creator → Belief**

The program is a simple tool for **thinking about life and what you believe**.
